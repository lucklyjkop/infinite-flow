# 开局加载与场景切换

开局进度由真实资源任务完成情况驱动。标题菜单在当前游戏图片、音效文件、Live2D 模型与运行时、地图贴图、地图渲染器准备完成后才开放；不再用固定 4.2 秒计时表示资源就绪。

进度数字和资源就绪门控独立于装饰动画。樱花树枝按约两秒的自身时钟蔓延，折扇按固定节奏展开，完整后停留等待资源。资源完成后树枝焚烧、折扇消散；缓存命中时也会衔接完短蔓延再焚烧，避免突然截断。减少动态时沿用静态画面和短淡出。

`game-preload.js` 收集本站 CSS、DOM 图片与少量动态视差图片，限制并发下载并保留解码后的图片引用。它等待存档、主神、系统空间、世界地图和声音模块的预加载任务。浏览器 HTTP 缓存负责磁盘缓存，本页保留解码资源；不要求下载 `art-source/`，也不缓存用户存档、API 回复或凭据。没有加入 Service Worker，不保证关闭浏览器之后可以离线重新打开网站。

资源失败会停在未完成进度并显示重试。已成功任务复用，只补失败任务；原 DOM 中失败的图片也重新加载，避免独立图片缓存恢复而实际页面仍空白。Live2D 资源请求失败必须在开局重试；确认渲染器不可用时沿用插画，并在本页保持该回退，避免点击存档时重新等待下载。

地图在开局准备两个停止运行的地形渲染器、相邻章节缓存和造景轮廓。打开时只获取当前系统画面并上传该截图，不再创建两套 GL 上下文或阻塞等待下一章节。返回系统空间时清除动态截图与天气，保留有界地图缓存；离开页面时释放。继续存档使用 320 毫秒渐隐，避免再创建并编译方块转场的 GL 程序；地图升起为 1.6 秒。

Live2D 在开局按实际响应式角色槽尺寸预热。相同尺寸不重复调整画布；隐藏节点的零尺寸通知不会撤销预热。停止姿态复制到一张 2D 画布，进入存档、暂停及场景截图复用该帧。正常人物动画保持非保留 WebGL buffer，不增加逐帧读回；第一张动态帧完成后移除冻结覆盖。

## 验证

- 启动失败、去重、重试、真实进度门控、DOM 图片恢复、模型网络失败与能力回退由 `tests/game-preload.test.cjs` 覆盖，纳入 Python 检查。
- 浏览器在开局完成后断网，真实点击继续、存档、系统与世界入口；此链路没有新增资源请求。新游戏命名流程也在断网状态通过。
- 地图反复开关始终保留两个渲染器；地图下标题雨和花瓣停止。静止下地形帧数不增加，雨帧继续；手机粒子上限、相机移动、减少动态效果、退出清理均已检查。
- 浏览器故障注入验证失败资源会阻止进入标题，恢复网络后重试可以修复原 DOM 图片并继续。

基线浏览器记录显示原地图点击后额外加载约 17.73 MB 图片，随后创建两套地形渲染器；系统截图还触发重复人物绘制。验证采用 Chromium 软件图形后端，耗时不代表真实设备的固定帧率。
