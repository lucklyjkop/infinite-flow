# 个人信息与对话窗口

## 个人信息

系统空间「行囊」入口改为「个人信息」，内部保留三个分区：个人详情、背包、能力。个人详情读取当前存档的通关数量、已结算任务、已觉醒能力和剩余契约点，并提供姓名、称谓、简介编辑。背包读取存档的 inventory，空档不填入示例装备；能力展示实际解锁的契印，入口可返回主神契约。

参考调研包括 [原神角色界面](https://www.hoyolab.com/article/1940832) 与 [星穹铁道角色界面](https://www.hoyolab.com/article/22102551) 的分区导航、角色与信息分层。按用户补充，个人形象来自上传或生图，因此将它缩为左侧身份卡，而非大幅角色展示。手机布局将身份卡收为顶部小卡。

最终配色为暖炭黑、暗绯红、香槟金，禁用墨绿。使用内置生图制作独立个人图标、透明形象框、红绸按钮、输入框、内容面板和背景；标签选中态通过同一贴图明暗与色彩平滑过渡。控件使用九宫格边框，固定花纹与圆角尺寸。文字为运行时排版，贴图不包含文案。

- 源图和完整提示词：`art-source/imagegen/player-profile/ui-generation-v2.json`。
- 运行资源：`loading-page/assets/player-profile/`，最终背景为 `profile-backdrop-final.webp`。
- 复现处理：Windows PowerShell 5.1 运行 `scripts/build-profile-art.ps1 -Ffmpeg <ffmpeg.exe>`。仅裁掉透明留白并按记录压缩，不重绘图像。
- 内置生成工具未披露模型版本或画质枚举，不声称具体版本。

姓名、称谓和简介保存至各自存档；上传图片以存档 ID 为键保存在 IndexedDB。支持 PNG、JPEG、WebP，输入最多 12 MB / 3200 万像素，等比处理至最长边 1200 像素、最多 2 MB。运行时使用 contain，保留比例，不强裁剪。上传失败保留原图；删除存档成功后清除对应图片。图片不写入源码或提交 GitHub，不会自动在另一台电脑出现。

## 对话窗口

点击关闭即可收起，不提供最小化。顶部拖动、右下角缩放、滚轮/触摸浏览记录；顶部复位按钮或双击拖动栏恢复初始位置。位置和尺寸仅保存在本机浏览器，始终限制在可视范围内。拖动栏和缩放角支持方向键，Shift 加快。

正文支持受限 HTML 富文本：段落、标题、强调、列表、表格、引用、代码、折叠块、HTTP(S) 链接和白名单样式。重建 DOM 后移除脚本、事件处理器、外部媒体、嵌套框架与定位样式，不执行模型生成的代码。

`POST /api/chat` 在 `Accept: application/x-ndjson` 时流式返回 thinking/text/done/error；默认 JSON 路由保持兼容。进度通过隔离 DSH worker 转发已有服务实际提供的公开字段，支持 OpenAI-compatible reasoning_content/reasoning、Anthropic thinking_delta、Responses reasoning summary 与输出文本。未提供思考内容时只显示等待状态，不生成或猜测思考过程。

思考内容与正文分开，正文出现时自动收起思绪；思绪不写入存档、不送 TTS，也不回传为对话历史。切换存档、离开系统空间或更改设置会取消当前请求，后到达的片段不会污染新对话。服务断流保留可见片段并提示中断，仅完整最终回复进入存档。

Live2D 思考状态沿用现有 Cubism 更新循环，平滑抬眼、轻偏头、闭合嘴部，头侧樱花加载徽记同步出现；正文开始、异常、取消或离开后恢复。没有新增持续画布渲染循环。

## 验证

存档、契约和前端对话单元测试 44 项；DSH 既有测试 20 项；流式字段解析、真实本地 SDK 假上游调用与 HTTP 路由测试 10 项。浏览器检查覆盖拖动/缩放、HTML 隔离、思绪切换、滚动位置、上传保存/移除/存档隔离、键盘操作、移动端布局、关闭后角色恢复。

浏览器检查使用隔离配置和临时存档，未读写用户当前浏览器的存档或接口密钥。真实外部服务认证未在这次界面改动中验证。
