# 命名存档与场景切换

开始游戏 → 选择并确认主神 → 输入存档名 → 从右向左的立体方块波浪 → 系统空间。取消命名不会创建存档；渲染失败后的同名重试会继续已创建的存档。

系统空间左上角与 Esc 均返回标题，使用与主神空间相同的方块过渡，从左向右展开。已展开区域直接显示标题页面的实时雨滴、花瓣等动画。

标题的「继续游戏」打开「轮回存档」。点击卡片恢复该存档的主神、系统空间导航位置与最近回复，再从右向左进入系统空间。没有存档时显示空状态，可直接开始新旅程。

## 存储范围

- 存档保存在当前浏览器、当前网站来源的 localStorage，键为 `infinite.saves.v1`，格式版本为 1。同名存档以独立 ID 区分。
- 当前实现保存主神、名称、创建/更新时间、系统导航选择、完整问答及世界地图关卡选择/已通关进度。地图默认零通关，只在实际玩法结算调用完成接口后推进，详见 [WORLD_MAP.md](WORLD_MAP.md)。
- 地图字段为 `progress.world = {completedCount,selected}`；每六关一卷，通关数为连续累计值，章节和关卡按需生成。旧 `completed` 数组按首卷连续前缀读取兼容，下次写入时转为紧凑格式。陈旧导航/对话更新不会降低通关数。
- 每份保留最近 100 组问答，并限制总文本长度；名称为 1–24 个 Unicode 码点。最多 100 份存档。
- 密钥、接口配置及临时 DSH 会话 ID 不进入存档。重新载入对话时，从当前存档提交近期历史，见 [DSH_CHAT.md](DSH_CHAT.md)。
- 换浏览器、换电脑、换网站端口/域名不会自动同步存档；清除网站数据会移除存档。GitHub 同步的是项目代码和资源。
- 无法解析或格式不兼容时保留原数据并提示重试；写入失败不覆盖原存档。

```sh
node --test tests/save-store.test.cjs tests/system-chat.test.cjs
python -m unittest discover -s tests -p "test_*.py"
python scripts/check-project.py
```
