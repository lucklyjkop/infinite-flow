# 命名存档与场景切换

开始游戏 → 选择并确认主神 → 输入存档名 → 从右向左的立体方块波浪 → 系统空间。取消命名不会创建存档；渲染失败后的同名重试会继续已创建的存档。

系统空间左上角与 Esc 均返回标题，使用与主神空间相同的方块过渡，从左向右展开。已展开区域直接显示标题页面的实时雨滴、花瓣等动画。

标题的「继续游戏」打开「存档管理」。点击卡片恢复该存档的主神、系统空间导航位置与最近回复；原存档页面保持完整，等系统空间及人物准备好后，原页面在 320ms 内直接淡出。没有存档时显示空状态，可直接开始新旅程。

存档进入使用 `InfiniteSceneTransition.createLive()`，直接保留浏览器绘制的存档 DOM，不再用手绘 Canvas 快照近似分段卡片，以消除切换瞬间的错位闪帧。淡出完成后先隐藏存档页面，再释放覆盖和动画；取消、加载失败、后台切换及减少动态时都会恢复原有状态。新游戏和返回标题的方块波浪继续使用原有画面捕获路径。

右键存档卡片、触屏长按 560ms，或聚焦卡片后按 Delete，都会打开删除确认弹窗。移动、滚动或取消触摸会撤销长按；松手不会误触发载入。确认中显示对应存档名称，默认聚焦「取消」，只有明确确认后才删除。写入失败保留原档并允许重试；删除当前存档后清除活动状态，列表焦点移到相邻卡片。离开存档页面会取消未完成的确认。

通用确认弹窗由 `common-dialog.js` 提供 `InfiniteDialog.confirm({title, message, confirmText, cancelText, opener, onConfirm, signal})`，返回 `Promise<boolean>`。`onConfirm` 可为异步操作；返回 false 保持弹窗，抛出带 `userMessage` 的异常显示简短错误。取消、Escape、点击遮罩或 AbortSignal 中止均返回 false。退出游戏与普通提示复用同一无字面板和按钮贴图。生成参数与提示词见 `../art-source/imagegen/save-management/generation.json`。

存档卡片使用等比端部和可扩展中段，保留原贴图的圆角、樱花、红线与头像框比例；头像按 1:1 显示。桌面居中单列，窄屏缩小卡片并截断长名称，避免整体纵向拉伸。

## 存储范围

- 存档保存在当前浏览器、当前网站来源的 localStorage，键为 `infinite.saves.v1`，格式版本为 1。同名存档以独立 ID 区分。
- 当前实现保存主神、名称、创建/更新时间、系统导航选择、完整问答及世界地图关卡选择/已通关进度。地图默认零通关，只在实际玩法结算调用完成接口后推进，详见 [WORLD_MAP.md](WORLD_MAP.md)。
- 地图字段为 `progress.world = {completedCount,selected}`；每六关一卷，通关数为连续累计值，章节和关卡按需生成。旧 `completed` 数组按首卷连续前缀读取兼容，下次写入时转为紧凑格式。陈旧导航/对话更新不会降低通关数。
- 每份保留最近 100 组问答，并限制总文本长度；名称为 1–24 个 Unicode 码点。最多 100 份存档。
- 密钥、接口配置及临时 DSH 会话 ID 不进入存档。重新载入对话时，从当前存档提交近期历史，见 [DSH_CHAT.md](DSH_CHAT.md)。
- 换浏览器、换电脑、换网站端口/域名不会自动同步存档；清除网站数据会移除存档。GitHub 同步的是项目代码和资源。
- 无法解析或格式不兼容时保留原数据并提示重试；写入失败不覆盖原存档。

```sh
node --test tests/save-store.test.cjs tests/system-chat.test.cjs
python -m unittest discover -s tests -p "test_*.py"
python scripts/check-project.py
```

浏览器核验包含命名取消、多存档恢复、长列表/窄屏、右键及长按删除、误触撤销、删除失败重试、确认焦点与跨标签页同步、重复点击保护、载入失败重试、迟到回复隔离，以及 WebGL 和 Canvas 两种方块波浪方向。
