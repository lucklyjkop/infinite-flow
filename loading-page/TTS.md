# 内置语音

系统设置的「TTS 模型设置」内置两条普通话声线，可调语速、音量并试听，也可自动朗读红妆的回复。

| 声线 | 性别 | 固定语音 ID |
| --- | --- | --- |
| 晓晓 | 女声 | `zh-CN-XiaoxiaoNeural` |
| 云希 | 男声 | `zh-CN-YunxiNeural` |

与大肥鱼项目采用相同的 [edge-tts](https://github.com/rany2/edge-tts) 在线合成方式，无需另填 TTS 密钥。这里的「内置」指已经配置好的声线和调用流程，不包含离线模型权重；朗读文本会发送到在线语音服务，断网时不能合成新的语音。服务不可用时显示错误，不以系统语音或固定录音冒充合成结果。

## 安装和启动

在仓库根目录执行，Windows 和 Linux 均使用项目自己的 Python 3.10+：

```sh
python scripts/setup-tts-runtime.py
python loading-page/serve.py
```

Linux 若只提供 `python3`，将上述命令中的 `python` 换为 `python3`。安装脚本在忽略目录 `output/tts-runtime/venv/` 中创建独立环境并安装固定的 `edge-tts==7.3.1`；不会改动全局 Python 或 DSH 环境。另一台电脑拉取项目后运行同一安装命令即可。安装成功后重启正在运行的预览服务。

## 行为与边界

- 试听使用当前设置草稿；「保存设置」后，后续对话采用保存的声线。音量还受声音页面总音量影响。
- 朗读在句子边界分段合成，并预取下一段；播放使用短淡入淡出。口型从解码 PCM 的 30 毫秒能量窗口计算，按音频时钟播放，加入静音滞回、渐开渐合与幅度归一化，避免短采样和音调造成抖动。模型使用同一嘴部网格连续变形，属于音节包络驱动，不是逐音素口型识别。
- 关闭试听、切换存档、离开系统空间或隐藏页面立即停止前端播放。迟到音频不再播放到新页面。浏览器取消请求后，已开始的服务端合成可能继续运行，直到完成或 60 秒上限；它不会启动无限重试。
- 服务端同时最多 2 个合成任务。额外请求返回「语音正在生成」，前端不会自动反复重试；瞬时网络故障由工作进程最多重试一次。证书校验失败或服务明确拒绝时不重试。
- 每次接口请求限 1500 个 Unicode 码点、75%–125% 语速及 8 MB 音频。工作进程只接受两条固定声线，不接受自定义地址、API 密钥或文件路径。
- 朗读文本和合成音频只通过内存传递，不写入后端音频缓存、日志或 Git。浏览器原有对话存档继续按 [SAVES.md](SAVES.md) 保存文本；语音文件不会进入存档。
- `GET /api/tts/status` 返回安装就绪状态及公开声线信息；`ready` 表示运行环境已经安装，不代表在线服务始终可用。`POST /api/tts` 只接受同源 JSON，成功返回 `audio/mpeg`，错误返回 JSON；响应禁止缓存。

## 来源和许可

第三方客户端来自 [rany2/edge-tts](https://github.com/rany2/edge-tts)，主许可为 **LGPLv3**，其中字幕工具模块单独使用 MIT 许可；完整说明见[上游 LICENSE](https://github.com/rany2/edge-tts/blob/master/LICENSE)。项目安装其未修改的软件包，通过独立进程调用，不将第三方环境或在线模型权重提交到仓库。客户端许可不等于在线语音服务或声线的独立离线模型授权。

## 检查

```sh
python -m unittest discover -s tests -p "test_tts_api.py" -v
```

自动测试使用受控工作进程与本地 HTTP 服务，不调用在线语音服务。真实男、女声的可用性需在装好运行环境后用页面「试听」验证。
