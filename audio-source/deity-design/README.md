# 主神空间原创声音设计

本组音效于 2026-11-08 为开始游戏、主神空间与返回标题制作，共 10 个独立声音。声音由项目内的程序化材质合成脚本原创制作；**没有读取或复用标题菜单、设置、纸张、骰子、火焰等既有录音**，没有调用外部音效 API，也不包含背景音乐。

使用宽带气流、受阻尼的非谐波材质共振、细颗粒接触与短早期反射模拟声音层次。所有 cue 使用各自固定的随机种子及不同的结构、力度包络和声像，单独生成采样。共用的是合成函数，不是音频 buffer。

| Cue | 时长 | 动画同步与设计 |
|---|---:|---|
| `start-cube-wave` | 2.60 秒 | 开始游戏时触发；单个波峰约在 0.77 秒，中央压力向两侧张开，之后衰减，不反复发出辐射波 |
| `start-cube-fracture` | 1.80 秒 | 主波开始后 0.70 秒触发；哑光石质块体碎裂，细碎颗粒逐渐减弱，不用尖锐玻璃炸裂 |
| `deity-cube-assemble` | 1.55 秒 | 主神空间拼合开始时触发；两侧向中央收拢，约 1.015 秒软落定，末尾两次极轻接缝接触 |
| `deity-return-wave` | 2.20 秒 | 返回立体波浪开始时触发；仅一个波峰，连续从左向右移动，尾端为主标题图像拼合落定 |
| `deity-inscribe` | 0.90 秒 | 主神空间标题书写；四个力度不同的纤维笔触，由左向右轻微移动 |
| `deity-branch` | 0.40 秒 | 主神标题花枝延展；短木纤维拉伸、极轻细枝接触 |
| `deity-hover` | 0.20 秒 | 主神头像悬停或键盘选中；连续柔纤维擦声，去掉硬接触与回声，25 毫秒淡入、80 毫秒淡出 |
| `deity-select` | 0.20 秒 | 点击主神头像；哑光陶石接触配短布面余音 |
| `deity-confirm` | 0.50 秒 | 确认主神；温暖、低沉、受阻尼的落定及柔和气流尾音 |
| `deity-back` | 0.22 秒 | 返回按钮；轻微左向退开声，随后开始独立返程波浪 |

制作命令：`python scripts/build-deity-audio.py`。需要 NumPy、SciPy、支持 libopus 的 FFmpeg（通过 `PATH`、`FFMPEG_BIN`，或可选 `imageio_ffmpeg` 寻找）。仅此命令会保留现有音效文件与 manifest 其他条目。完整 `scripts/build-game-audio.py` 也会在最后调用此脚本，避免重建后丢失本组音效。

局部修改可用 `python scripts/build-deity-audio.py --only deity-hover`，或调用 `build(names=['deity-hover'])`。此模式仅编码指定 cue，保留其他交付文件与完整设计记录；试听合辑使用已有本机 WAV 拼接，不重编码其他声音。

头像悬停声已按实机反馈改为单段平缓纤维摩擦：主体频带 480–2050 Hz，去除石质碰击、颗粒脉冲与短回声，限制低频敲击及高频沙点。新版时长 0.20 秒、RMS -35.99 dBFS、true peak -24.85 dBFS，起止边界差为 0；其余 9 条主神声音及 17 条既有声音保持原交付字节不变。

运行交付：`loading-page/assets/audio/` 中同名 Ogg Opus 文件，48 kHz 双声道、112 kbps VBR。每条均有短淡入和长短匹配的淡出，短房间反射避免硬截断。试听无损 WAV 与合并试听文件写入本机 `output/audio-design/deity/`，不提交临时输出。

`design.json` 保留每条声音的种子、说明、交付及母带 SHA-256、时长、解码后峰值、4 倍超采样 true peak、RMS 与首尾边界差。当前最强交付 true peak 为 -9.41 dBFS；短声最大边界差 0.000305。10 个母带及交付哈希均互不相同，未匹配既有声音文件。该测量是数字信号检查；最终混音还应以游戏中实际扬声器或耳机试听为准。

建议以固定 playbackRate 播放四条转场音效，避免时间随机变化破坏波峰与拼合落点同步。新音效本身已减弱，运行时应通过游戏现有 master/effects 母线统一控制，不另行提升系统音量。
