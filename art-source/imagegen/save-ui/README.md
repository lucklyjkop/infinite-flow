# 轮回存档 UI 素材

本套素材使用内置 `image_gen.imagegen` 生成，沿用系统空间的月夜、墨色、红绳与樱花主题。提示词、参考图和原始生成文件位置见 `generation.json`。工具未披露实际模型版本及画质档位。

- `archive-backdrop.png`：完整存档页面背景，无烘焙文字或按钮。
- `archive-card.png`：带透明通道的卡片底纹，文字和头像由运行页面叠加。
- `name-panel.png`：命名面板。生成时要求透明背景，但实际返回 RGB 图像，未实现透明；页面通过缩放背景并使用圆角裁切，隐藏面板外缘的棕色底，原始图像未进行像素处理。

运行资源位于 `loading-page/assets/save-ui/`；悬停的红线、光晕和缩放由 CSS 动画控制。存档名、时间、正文均为真实文本。
